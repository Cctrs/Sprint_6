Sprint_6   
В рамках спринта были написаны автотесты, использующие паттерн POM.  
Проект разбит на три страницы: базовая, главная, страница заказа.    
Локаторы разбиты в соответствии со страницами.   
Группы тестов разбиты по функциональности (проверка FAQ, размещение заказа и редиректы).   
Два теста параметризованы. Наборы данных для заполнения формы заказа лежат в отдельном файле.   
В папке allure_results лежит отчет о прохождении тест-рана, вызывается через "allure serve allure_results".   
Все необходимые библиотеки в файле requirements.txt
